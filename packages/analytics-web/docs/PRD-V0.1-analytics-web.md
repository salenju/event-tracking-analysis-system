# 埋点分析看板 产品需求文档（PRD）V0.1

| 项 | 内容 |
| --- | --- |

| 版本 | V0.1.0（2026-11-22） |

| 金额口径 | 看板不直接展示金额；事件属性中的 `payAmount` 与 `currency` 原样呈现在会话明细的 JSON 中，币种由上报方决定 |

## 2. 背景与目标

埋点 SDK 与接收接口已落地，需要一个看板把采集到的数据变成可执行的结论。本期目标聚焦三点：看清收银台漏斗的环节转化、下钻到具体流失会话还原路径、提供应用凭据与成员管理以支撑多业务接入。

本期范围（已实现）：转化漏斗页、事件概览页、体验指标页、飞书与本地登录、管理后台、一键复制接入代码、无后端时的假接口服务。

本期明确不做：在看板中修改或删除埋点事件、实时秒级刷新、自定义图表编排、数据导出、消息通知、多租户工作区、前端单元测试框架（当前仅静态类型校验）。

## 4. 业务流程

**FLOW-001 漏斗查询与下钻**：路由进入漏斗页 → 读取漏斗列表并构造默认查询（首个漏斗的 key、appId、env 与最近 7 天）→ 拉取漏斗结果 → 渲染指标卡、漏斗图与分步表 → 点击色块或表格行打开会话抽屉 → 分页加载该步骤流失会话 → 点击单条会话加载事件时间线。

**FLOW-002 事件概览**：初始化查询 → 拉取事件概览 → 渲染事件总量、事件种类、峰值时间段与统计区间 → 在事件量与独立用户之间切换折线序列 → 渲染按触发量降序的事件明细表。

**FLOW-003 体验指标**：并发请求性能、停留与完整性三个接口 → 渲染加载性能的指标卡、六项分位数表与三个维度分组表 → 渲染停留时长的样本指标与两个分组表 → 渲染完整性批次报告并对缺失记录给出告警。

**FLOW-004 登录**：登录页读取认证配置 → 飞书二维码模式下在 iframe 内打开授权地址，回调页通过 `postMessage` 回传 token → 前端把 token 写入本地存储并回服务端换取用户信息 → 授权跳转模式下 token 放在 URL 片段中，回调页读取后立即替换路由清除地址栏凭证 → 本地调试模式下用用户名调用调试登录接口。

**FLOW-005 应用管理与接入**：管理员进入后台 → 加载应用列表与签名配置 → 创建应用时校验同环境重名 → 服务端返回明文密钥仅显示一次 → 凭据弹窗展示应用 ID、密钥、环境、一键复制的脚本标签与凭据备份 JSON → 后续可轮换密钥、停用启用、删除应用。

## 5. 业务规则

| 编号 | 规则 |
| --- | --- |
| BR-001 | 默认环境为 `prod`；默认时间范围为最近 7 天（起算日按本地零点到当前时刻）；快捷区间提供最近 24 小时、7 天、30 天、90 天。 |
| BR-002 | 漏斗列表来自服务端元数据接口；列表为空时显示配置提示且不发起漏斗查询；默认选中第一个漏斗并同步填充应用与环境。 |
| BR-003 | 漏斗指标卡展示首步会话数、末步会话数、整体转化率与最大流失环节；最大流失环节按相邻步骤流失数取最大，首步不参与比较。 |
| BR-004 | 漏斗图按配置顺序展示，不做重排序；步骤表格的到达会话进度条最小宽度 2%；首步的「查看流失」禁用。 |
| BR-005 | 漏斗与概览只统计服务端标记为业务事件且按会话去重的记录；漏斗口径与相邻窗口由服务端配置决定，看板只展示窗口提示。 |
| BR-006 | 概览事件按触发量降序；占比为单事件触发量除以全部事件触发量；独立用户列为各时间桶去重后求和，即非全区间去重。 |
| BR-007 | 趋势图按粒度自动聚合；当时间桶超过 24 个时显示缩放条；默认指标为事件量，可切换为独立用户。 |
| BR-008 | 性能指标共六项：最大内容绘制、首次内容绘制、首字节时间、页面加载完成、交互响应延迟、累积布局偏移；毫秒类展示为整数加单位，布局偏移展示三位小数。 |
| BR-009 | 体验指标分位数包含平均值、P50、P75、P95 与最大值；页面、国家、设备三个分组表按最大内容绘制的 P75 展示。 |
| BR-010 | 停留时长样本来自页面停留记录，不足 1 秒的片段不上报；按结束原因分组展示隐藏、卸载与前页切换等触发来源。 |
| BR-011 | 完整性报告展示批次数、声明条数、实际条数与缺失条数；缺失条数大于 0 时显示告警并提示排查拒绝与跳过记录。 |
| BR-012 | 看板请求统一携带 Bearer 令牌；收到 401 时清除令牌并跳转登录页，携带原目标地址作为回跳参数；业务失败响应统一转为前端错误。 |
| BR-013 | 登录回调令牌不校验消息来源，前端拿到后必须回服务端换取用户信息，校验失败时清除令牌并提示凭证失效。 |
| BR-014 | 管理后台的应用名在同一环境下大小写不敏感重名校验；来源为环境变量的应用在页面上只读，不提供轮换、停用与删除入口。 |
| BR-015 | 轮换密钥与停用应用前必须二次确认；密钥明文只在创建时显示一次；删除应用保留历史事件。 |
| BR-016 | 脚本标签接入代码只包含 appId，不含环境、密钥与上报地址；上报地址按 SDK 脚本所在域推导，SDK 文件地址来自服务端配置或当前站点的 SDK 路径。 |
| BR-017 | 服务端开启签名校验时，凭据弹窗提示脚本标签形态会被丢弃，需改用带签名的构造函数接入。 |
| BR-018 | 成员管理列表禁止修改自己的角色与启用状态；角色变更后重新拉取当前用户信息以刷新界面权限。 |
| BR-019 | 已登录用户访问登录页时直接进入漏斗页；服务端未开启鉴权时未登录用户可直接访问看板，但管理后台仍要求登录与管理员角色。 |
| BR-020 | 漏斗与概览筛选支持国家码与设备类型；体验接口不传钱包类型；国家码输入自动转为大写并去除首尾空格。 |
| BR-021 | 所有列表与抽屉使用客户端分页，会话抽屉每页 20 条并支持加载更多；漏斗图与趋势图高度固定，容器尺寸变化时自动重绘。 |
| BR-022 | 无后端时假接口服务提供看板所需全部只读与管理接口，使用固定漏斗配置与固定样本数据，飞书登录接口返回禁用状态。 |

## 6. 数据规则

| 数据对象 | 关键字段 |
| --- | --- |
| 漏斗定义 | 标识、名称、应用 ID、环境、步骤事件名数组、相邻窗口分钟数 |
| 漏斗结果 | 起止时间、钱包类型、国家、设备、总会话数、各步骤的序号、事件名、到达数、相对上一步转化率、相对首步转化率、流失数 |
| 流失会话 | 步骤序号、步骤事件名、会话列表（会话 ID、开始时间、最后到达时间）、是否有下一页 |
| 会话明细 | 会话 ID、应用 ID、环境、时区偏移、事件序列（事件名、记录类型、钱包类型、失败原因、订单号、用户 ID、发生时间、属性） |
| 事件概览 | 应用 ID、环境、粒度、时区偏移、时间点列表（时间桶、事件名、触发量、独立用户） |
| 体验指标 | 会话数、记录数、六项指标的分位统计、按页面与国家与设备的分组、停留统计与分组、完整性报告 |
| 应用 | 应用 ID、名称、环境、状态、来源、掩码密钥、备注、创建人与时间 |
| 成员 | 用户 ID、姓名、头像、邮箱、角色、状态、来源、最近登录时间 |
| 签名配置 | 是否要求签名、签名时间窗、上报路径、环境、对外上报域名、SDK 文件地址 |

筛选条件由漏斗标识、应用、环境、钱包类型、国家、设备、起止时间组成；接口层会剔除值为空的字段再拼接查询串。

## 11. 验收标准

### AC-001 漏斗默认加载
- 给定 服务端返回至少一个漏斗且当前环境已开启鉴权并完成登录；
- 当 用户首次访问漏斗页；
- 则 页面自动选中第一个漏斗，使用其应用与环境以及最近 7 天发起查询，并渲染四个指标卡、漏斗图与步骤表格。

### AC-002 漏斗无配置提示
- 给定 服务端返回空的漏斗列表；
- 当 用户访问漏斗页；
- 则 页面显示检查漏斗配置文件的提示，并且不发起漏斗数据请求。

### AC-003 流失会话下钻
- 给定 漏斗结果中存在第二步的流失会话；
- 当 用户点击漏斗图第二步色块或表格第二行；
- 则 打开流失会话抽屉，按每页 20 条加载列表，点击其中一条后展示该会话按时间排序的事件时间线。

### AC-004 筛选条件生效
- 给定 页面存在两条应用不同或国家不同的会话数据；
- 当 用户在筛选栏选择其中一个应用与一个国家码后点击查询；
- 则 请求参数包含所选应用与大写的国家码，漏斗与概览结果只反映该组合的数据。

### AC-005 事件概览切换
- 给定 所选区间内存在多个事件与多个时间桶；
- 当 用户在事件概览页把指标从事件量切换为独立用户；
- 则 折线图序列按独立用户重绘，事件明细表的占比之和为 100%，并在页面提示独立用户为按桶求和。

### AC-006 体验指标展示
- 给定 服务端返回六项性能指标、停留统计与完整性报告；
- 当 用户访问体验指标页；
- 则 页面展示六项分位统计表与三个维度分组表，最大内容绘制以毫秒展示、累积布局偏移以三位小数展示，并在缺失条数大于 0 时显示告警。

### AC-007 飞书扫码登录
- 给定 服务端配置了飞书应用且认证配置返回开启状态；
- 当 用户打开登录页并在 iframe 内完成扫码，回调页把令牌回传给父窗口；
- 则 前端回服务端换取用户信息，成功后跳转漏斗页，失败时清除令牌并显示凭证失效提示。

### AC-008 令牌过期处理
- 给定 浏览器保存的令牌已被服务端判定过期；
- 当 用户在漏斗页触发任意查询；
- 则 前端清除本地令牌并跳转到登录页，登录页地址携带原访问路径与过期提示。

### AC-009 应用创建与密钥展示
- 给定 管理员已登录且当前环境不存在同名应用；
- 当 管理员填写名称与环境并提交创建；
- 则 应用出现在列表中，弹窗展示明文密钥与一键复制代码，关闭弹窗后列表只显示掩码密钥。

### AC-010 接入代码内容
- 给定 管理员打开某个后台创建应用的凭据弹窗；
- 当 管理员查看或复制接入代码；
- 则 代码初始化指令只带 appId，脚本元素标识为约定的 SDK 标识，脚本地址为服务端配置或当前站点的 SDK 路径，代码中不出现环境、密钥与上报地址字面量。

### AC-011 成员角色控制
- 给定 当前登录者角色为管理员且列表中存在普通成员与自己；
- 当 管理员把普通成员改为管理员，并尝试修改自己的角色；
- 则 普通成员角色更新成功且刷新当前会话信息，自己的角色控件保持禁用。

### AC-012 无后端本地运行
- 给定 本机没有可用的后端服务与数据库；
- 当 启动假接口服务并把开发代理指向它；
- 则 漏斗、概览、体验、管理后台页面均可加载固定样本数据，飞书登录入口显示未配置状态，本地调试登录可用。

## 12. 非功能需求

- **构建**：类型检查与打包一体化，构建命令先执行静态类型校验再生成产物；产物关闭源码映射，单块体积告警阈值设为 1200 KB。
- **体积与加载**：路由组件按需加载；图表库按需注册所需图表与组件，不引入整包。
- **兼容性**：面向主流现代浏览器；时间格式化使用中文地区与 24 小时制；窄屏下内容区切换为单列。
- **可观测性**：接口非 2xx 与业务失败统一弹出错误提示；认证配置与会话状态在内存中缓存，避免逐次请求重复拉取。
- **可维护性**：无全局状态管理库，会话状态用轻量响应式单例；API 客户端集中处理地址拼接、令牌、错误与登录跳转。

## 13. 依赖与风险

| 项 | 说明 |
| --- | --- |
| 后端依赖 | 依赖 `track-server` 提供全部查询与管理接口；接口返回结构与前端类型定义需保持一致 |
| 部署依赖 | 开发期由 Vite 代理转发接口，生产期由反向代理把同源接口转发到后端；接口基地址默认留空 |
| SDK 依赖 | 开发期通过 Vite 中间件把 SDK 产物映射到 SDK 路径；若产物未构建，后台生成的接入代码在本地不可用 |
| 测试风险 | 仓库内没有前端自动化测试，只有静态类型校验与构建验证；交互回归需人工完成 |
| 安全边界 | 令牌存于本地存储，存在跨站脚本窃取风险；当前看板不加载第三方脚本，后续引入时需改用只读cookie方案 |
| 数据口径 | 独立用户为按时间桶求和而非全区间去重，与常见直觉不同，界面已提示但解读时仍需留意 |
| 时区 | 前端不向后端传时区偏移，展示时间使用浏览器本地时区，与服务端默认时区不同时会出现显示差异 |

## 14. 待确认问题

- 生产环境的反向代理配置未纳入本仓库，接口路径与 SDK 静态路径的映射需在部署时确认。
- 服务端返回的时区偏移目前只在概览页展示，是否在其他页面统一展示或参与格式化需确认。
- 是否为看板补充前端自动化测试框架与关键交互用例需排期决策。
- 独立用户按时间桶求和的口径是否要改为全区间去重，需与数据分析方确认后再调整服务端。
- 本地调试登录在生产环境恒不可用，是否需要提供企业内部的其他免飞书登录方式需确认。
- 服务端关闭鉴权且用户未登录时，路由守卫会放行管理后台，实际拦截依赖管理接口返回的认证失败；此时是跳转到登录页还是展示权限空态需要统一。
